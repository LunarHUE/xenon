<Section title="type">

Button defaults to `type="button"`. Set `type="submit"` when it should submit its
parent form.

The default stops a button from submitting a form by accident.

<Section title="pending">

Use `pending` while an action is in progress. Button stops activation and stays
focusable.

Change the label yourself, like "Saving…". `pending` doesn't add one.

<Section title="Links">

Render Button as a link with `as="a"` and an `href`. It stays a native link, so
only Enter follows it.

While the link is disabled or pending, Button removes the `href`. The link can't
be followed and leaves the tab order until the state clears.

```tsx title="upgrade.tsx"
<Button as="a" href="/billing" pending={isRedirecting()}>
  Upgrade plan
</Button>
```

</Section>

<Section title="Tailwind">

Style each state through the attribute Button sets for it. For example,
`data-pending:opacity-70` dims a pending button.

The [API tab](/docs/components/button/api/#data-disabled) lists every
attribute. The previews on these pages use example styles. Keep keyboard focus
visible in every state.

The [Styling guide](/docs/styling/) covers data variants and focus styles for
every component.
