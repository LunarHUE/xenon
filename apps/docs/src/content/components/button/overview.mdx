---
title: Button
description: A button with consistent keyboard, focus, and disabled behavior.
group: actions
---

<Section title="Example">

Use Button to submit a form or trigger an action. It renders a native button by
default.

```tsx
<Button>Save changes</Button>
```

</Section>

<Section title="Behavior">

- **Button** triggers an action.
- **Toggle** represents an on/off pressed state.
- **Link** navigates to another location.

</Section>
