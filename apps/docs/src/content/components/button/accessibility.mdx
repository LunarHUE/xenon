<Section title="Semantics">

Button follows the [WAI-ARIA button pattern](https://www.w3.org/WAI/ARIA/apg/patterns/button/).
The default host is a native button, and its visible label is the accessible
name.

What Button sets depends on the host you pass to `as`.

| Host               | Role            | Disabled                   | Pending                    |
| ------------------ | --------------- | -------------------------- | -------------------------- |
| `button`, default  | Native button   | `disabled`                 | `aria-disabled`            |
| `input`            | Native input    | `disabled`                 | `aria-disabled`            |
| `a` with an `href` | Native link     | `aria-disabled`, no `href` | `aria-disabled`, no `href` |
| Anything else      | `role="button"` | `aria-disabled`            | `aria-disabled`            |

An icon-only button has no visible label, so give it one with `aria-label`.

```tsx title="accessible-name.tsx"
<Button aria-label="Close dialog">
  <CloseIcon aria-hidden="true" />
</Button>
```

</Section>

<Section title="Keyboard">

Every host except a link activates like a native button.

| Key                               | Behavior                                                            |
| --------------------------------- | ------------------------------------------------------------------- |
| <Kbd>Tab</Kbd>                    | Moves focus to the button.                                          |
| <Kbd>Shift</Kbd> + <Kbd>Tab</Kbd> | Moves focus to the previous focusable element.                      |
| <Kbd>Enter</Kbd>                  | Activates the button when the key goes down. On a link, follows it. |
| <Kbd>Space</Kbd>                  | Activates the button when the key is released. Links ignore it.     |

</Section>

<Section title="Focus">

| State                                | In tab order | Activation |
| ------------------------------------ | ------------ | ---------- |
| Enabled                              | Yes          | Allowed    |
| `disabled`                           | No           | Prevented  |
| `pending`                            | Yes          | Prevented  |
| `disabled` + `focusableWhenDisabled` | Yes          | Prevented  |

A link leaves the tab order while disabled or pending, because Button removes
its `href`.

A focusable disabled button uses `aria-disabled`. If it needs to explain why it
is unavailable, connect the reason with `aria-describedby`.

</Section>

  </Definition>
