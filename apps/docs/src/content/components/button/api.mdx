<Props type="ButtonProps<T>" note="Native props are forwarded">

The button. Renders a `<button>`, or the element you pass to `as`.

<Prop name="disabled" type="boolean | ''" default="false">

Disables the button. Clicks, Enter and Space don't activate it, and your
`onClick` doesn't run.

Solid's empty attribute value, `disabled=""`, also disables the button.

A native button or input gets the `disabled` attribute and leaves the tab order.
Other hosts get `aria-disabled` and lose their tab stop.

```tsx title="disabled.tsx"
<Button disabled>Save changes</Button>
```

</Prop>

<Prop name="pending" type="boolean" default="false">

Blocks activation while work is in progress. The button stays focusable and gets
`aria-disabled`.

A link loses its `href` while pending, so it can't be followed.

```tsx title="pending.tsx"
<Button pending={isSaving()}>{isSaving() ? 'Saving…' : 'Save'}</Button>
```

</Prop>

<Prop name="focusableWhenDisabled" type="boolean" default="false">

Keeps a disabled button in the tab order. Use it when users need to find the
action and learn why it is unavailable.

Line 4 connects the reason to the button. Links ignore this prop.

```tsx title="focusable-when-disabled.tsx"
<Button
  disabled
  focusableWhenDisabled
  aria-describedby="reason"
>
  Publish
</Button>
<p id="reason">Add a title before publishing.</p>
```

</Prop>

<Prop name="as" type="ValidComponent" default="'button'">

The element or component to render. `a` with an `href` stays a native link and
`input` a native input. Any other host gets `role="button"`, a tab stop, and
Enter and Space activation.

A custom component must pass its props and ref on to the element it renders.
See [Composition](/docs/composition/#ref).

```tsx title="as.tsx"
<Button as="a" href="/pricing">
  See pricing
</Button>
```

</Prop>

<Prop name="type" type="'button' | 'submit' | 'reset'" default="'button'">

The native button type. `submit` submits the associated form and `reset` resets it.
These three values are supported for both the default button and `as="input"`.

Omitting the prop defaults to `button`. Explicit `type={undefined}` removes the
attribute, including after a reactive value changes. A button without a type
usually submits its associated form; an input without a type becomes a text input.
Keep an explicit type when rendering an input as a button.

Other hosts retain their own `type` prop meaning. For example, an anchor's `type`
describes the linked resource's media type.

```tsx title="type.tsx"
<form onSubmit={save}>
  <Button type="submit">Save</Button>
</form>
```

</Prop>

<Prop name="role" type="string" default="'button'">

The role for a host that isn't a button, input or link. With `role="link"`, only
Enter activates it, as with a native link.

Native hosts keep their own keyboard behavior.

```tsx title="role.tsx"
<Button as="span" role="link" onClick={openProfile}>
  Ada Lovelace
</Button>
```

</Prop>

<Prop name="autofocus" type="boolean | ''" default="false">

Focuses the button once it has rendered, and sets the `autofocus` attribute and
`data-autofocus`.

Both `true` and the empty attribute value `""` enable autofocus.

Focus goes through the ref, so a custom `as` component has to forward it.

```tsx title="autofocus.tsx"
<Show when={step() === 'confirm'}>
  <Button autofocus onClick={confirm}>
    Confirm
  </Button>
</Show>
```

</Prop>

<Prop name="ref" type="ComponentProps<T>['ref']">

Uses the selected host's native Solid ref type. The default host infers
`HTMLButtonElement`; `as="a"` infers `HTMLAnchorElement`. Callback arrays,
including nested arrays and undefined entries, compose with Xenon's internal ref.

In development, Button logs an error when a custom `as` component never passes
the element back.

```tsx title="ref.tsx"
let button: HTMLButtonElement | undefined

;<Button ref={(el) => (button = el)}>Save</Button>
```

</Prop>

<Attributes>
  <Attribute name="data-disabled">Present while `disabled` is set.</Attribute>
  <Attribute name="data-pending">Present while `pending` is set.</Attribute>
  <Attribute name="data-autofocus">Present while `autofocus` is set.</Attribute>
</Attributes>

</Props>
