a native `<input type="checkbox">` by default.

<Section title="When to use">

<Definitions>
  <Definition term="Checkbox">One choice that is checked or not. The only one here with a mixed state.</Definition>
  <Definition term="Switch">A setting that is on or off, like notifications. Sets `role="switch"` and has no mixed state.</Definition>
  <Definition term="CheckboxGroup">A set of checkboxes under one name. Submits one entry per checked item.</Definition>
  <Definition term="Toggle">A button that stays pressed and exposes `aria-pressed`. Submits nothing with a form.</Definition>
</Definitions>
