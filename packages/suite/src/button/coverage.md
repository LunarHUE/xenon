# Button coverage

The old backlog contained 35 TODOs and 8 skipped registrations. Some were real browser-test gaps; others recorded competing library APIs or browser rules. This inventory separates those cases without changing the research specs.

The new backlog files use real Chromium keyboard and pointer input through `vitest/browser`. Native form validation, commands, submission, label state, shadow focus and scroll behavior are exercised on mounted Button hosts. A runnable ID indicates source assertions, not a stored passing result.
