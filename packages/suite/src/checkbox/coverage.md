Every source ID in the checkbox section of `docs/spec/checkbox.md` is accounted for here. The separate checkbox-group research section is outside this standalone control API. Research bullets are preserved; library candidates do not automatically become supported props. Superseded rows record architecture choices, not passing claims for the rejected behavior. No TODO or skipped registrations stand in for assertions.

Native validation and implicit submission use trusted Chromium keyboard/pointer actions in Vitest Browser Mode. Server rendering and hydration live in the shared E2E fixture. Field integration is additionally exercised by `../field/contract.tsx`.
